Explore the North - photo gallery (shown on itinerary.html?item=north)

Replace img1.jpg ... img10.jpg with your own photos. Keep the same file names.
The files that exist are shown, in order. If a file is missing, it is skipped; with none, the gallery is hidden.

Format: JPG (photos compress much smaller than PNG; use PNG only for graphics/transparency).
Size: landscape, 3:2, about 1600 x 1067 px, JPG quality 75-82, ideally under 300 KB each.
Put the strongest photo first (img1.jpg).
Each itinerary can have its own folder: images/itineraries/fuerteventura/<itinerary-name>/ and a `gallery` entry in itineraries-data.js.
