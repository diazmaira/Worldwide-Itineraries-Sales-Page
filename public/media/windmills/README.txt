UPLOAD HERE: photos and audio of "Fuerteventura windmills"

In GitHub open this folder (public/media/windmills), click Add file > Upload files,
drag your files in and click Commit changes. You can add many files at once.

Names (lowercase, no spaces, two digits for the stop number):
  cover.jpg          cover photo
  stop-01.jpg        photo of stop 1
  stop-01-en.mp3     audio of stop 1 in English
  stop-02.jpg ...    and so on

In content/windmills.html write only the file name, for example:
  <img src="stop-01.jpg">   <audio src="stop-01-en.mp3">

Limits: a browser upload accepts files up to 25 MB each.
Reminder: files in this folder are public if someone knows the exact address.
